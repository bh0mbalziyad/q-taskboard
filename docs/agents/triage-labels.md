# Triage Labels

This repo uses a reduced label vocabulary: only two labels. The skills' other canonical triage roles are not used here; don't create or apply labels for them.

| Label in mattpocock/skills | Label in our tracker | Meaning                                                  |
| -------------------------- | -------------------- | -------------------------------------------------------- |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent                  |
| _(none)_                   | `done`               | Work is complete (apply when closing the issue)          |
| `needs-triage`             | _(not used)_         |                                                          |
| `needs-info`               | _(not used)_         |                                                          |
| `ready-for-human`          | _(not used)_         |                                                          |
| `wontfix`                  | _(not used)_         |                                                          |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table. If a role is marked not used, skip that step.
